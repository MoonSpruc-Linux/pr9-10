### Що зроблено:

### 1. Сторінка каталогу

Створив окрему сторінку `catalog.html`, на якій відображається список елементів.

---

### 2. JSON з даними

Створив файл `data/items.json`.

У ньому має є масив об’єктів з полями:

- id
- title
- category
- description
- price та rating

---

### 3. Завантаження даних через fetch

Реалізував отримання даних із JSON-файлу через:

- fetch()
- async/await
- try/catch для обробки помилок

---

### 4. Стан інтерфейсу

Реалізував три стани:

- loading (під час завантаження даних)
- error (якщо сталася помилка)
- success (відображення каталогу)

---

### 5. Динамічний рендер карток

Картки повинні створюватися через JavaScript.

Заборонено:

- прописувати картки вручну в HTML

Обов’язково:

- функція render()
- створення елементів через JS або innerHTML на основі масиву даних

---

### 6. Пошук

Реалізував live search:

- пошук по title та description
- оновлення результатів під час введення тексту
- без перезавантаження сторінки

---

### 7. Фільтрація за категоріями

Реалізував фільтр:

- категорії (наприклад: all, frontend, design)
- показ тільки відповідних елементів
- робота разом із пошуком

---

### 8. Сортування

Додав сортування:

- за ціною або рейтингом
- порядок має змінюватися в DOM

---

### 9. Обране (localStorage)

Реалізував систему “обране”:

- додавання/видалення елементів
- збереження в localStorage
- відновлення після перезавантаження сторінки

---

### 10. Порожній результат

Якщо після пошуку або фільтрації нічого не знайдено:

- показати повідомлення “нічого не знайдено”
- не показувати порожній список

### Для запуску:

- варіант 1: просто відкрити ці файли
- варіант 2: відкрити в редакторі завдяки розширенню live-server
